## 数据点

| 字段名称 | 描述 |
|------------|-------------|
| `url` | 公司在 Pitchbook 上的资料页面网址。 |
| `id` | Pitchbook 为每家公司分配的唯一标识符。 |
| `company_name` | 公司的正式名称。 |
| `company_socials` | 公司社交媒体资料的链接。 |
| `year_founded` | 公司成立的年份。 |
| `status` | 当前经营状态，例如正常运营、已被收购或已停业。 |
| `employees` | 公司大致的员工人数。 |
| `latest_deal_type` | 最新的交易类型，例如并购或融资轮次。 |
| `financing_rounds` | 公司经历的融资轮次总数。 |
| `investments` | 公司进行的投资数量。 |
| `description` | 公司业务和产品/服务的简要概述。 |
| `contact_information` | 联系信息，包括网站和电子邮件地址。 |
| `patents` | 公司持有的专利信息。 |
| `competitors` | 行业内主要竞争对手的列表。 |
| `research_analysis` | 针对公司业务开展的报告与分析。 |
| `patent_activity` | 近期专利申请及相关活动的详细信息。 |
| `all_investments` | 公司获得的所有投资的完整列表。 |
| `faq` | 与公司资料相关的常见问题。 |
| `latest_deal_amount` | 最新交易或投资的已披露金额。 |
| `latest_deal_amount_value` | 最新交易金额的数值。 |
| `latest_deal_date` | 公司最近一次交易的日期。 |


## 使用场景

### 1. 投资分析
通过分析公司资料和融资详情，利用此数据集评估市场趋势和投资机会。

### 2. 竞争力基准分析
使用此数据集比较竞争对手的业务战略和绩效指标，为战略规划和市场定位提供支持。

### 3. 市场研究
通过分析公司描述、成立年份和交易类型开展深入的市场研究，洞察行业动态。
